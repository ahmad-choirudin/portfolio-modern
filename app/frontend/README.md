# Portfolio — Ahmad Choirudin

React 18 + Vite 5 + Tailwind 3 + TypeScript.

    pnpm install      # atau npm install
    pnpm dev          # http://localhost:5173
    pnpm build        # hasil di dist/

## Yang perlu kamu isi
- Foto: taruh `public/hero.jpg` dan `public/about.jpg`, lalu ubah `heroImage` / `aboutImage` di `src/data/site.ts`.
- Link sosial & email: `src/data/site.ts`.
- Link sertifikat: `src/data/certificate.ts`.
- Teks & gambar proyek: `src/data/projects.ts` (gambar di `public/projects/`).
- Animasi: `src/index.css` (bagian bawah) dan `components/site/CursorLayer.tsx`.
